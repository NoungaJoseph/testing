# Enako-Outreach

Enako Outreach is a community impact foundation dedicated to transforming lives through education, healthcare, and sustainable development initiatives in Cameroon.

## 🎯 Mission

Empower communities in Cameroon through quality education support, healthcare initiatives, and sustainable development programs that create lasting positive change.

## 🌍 Focus Areas

### Education & Scholarships
- Primary School Support
- Secondary School Support
- University Scholarships
- Teacher Rewards Program
- Youth Empowerment

### Community & Health
- Clean Water Initiative
- Community Health Support
- Single Mothers Assistance
- Healthcare & Medical Outreach

### Social Impact
- Focus Communities Development
- Skills & Leadership Training
- Material Support & Assistance

## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/NoungaJoseph/testing.git

# Navigate to project directory
cd enako

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production

```bash
npm run build
```
